# 🛍️ Mini Shop

Mini Shop is a simple and responsive shopping website created using
HTML, CSS, and JavaScript.

## ✨ Features

- Product cards with images and prices
- Search products
- Add to Cart functionality
- Dynamic cart item count
- Responsive design for mobile and desktop
- Simple and clean user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📦 Products

The website contains sample products such as:

- T-Shirt
- Sneakers
- Watch
- Backpack

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Search for products and use the Add to Cart button.

## 🎯 Project Purpose

This project was created as a beginner-level web development practice
project to understand HTML structure, CSS styling, JavaScript events,
search functionality, and basic shopping cart interaction.

## 📱 Responsive Design

The website is designed to work on both desktop and mobile screen sizes.
